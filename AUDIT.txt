1. STACK TECHNIQUE
================================================================================

  Framework        : React 18.3.1 avec TypeScript 5.8
  Bundler          : Vite 5.4  (config : vite.config.ts)
  Routing          : react-router-dom v6 (BrowserRouter, Routes, lazy)
  Styles           : CSS Modules (*.module.css par composant) + global CSS
  Animations       : framer-motion 12 (transition de pages) + keyframes CSS
  Icônes           : lucide-react 0.511
  Markdown         : react-markdown 10 + remark-gfm 4
                     (rendu du fullDesc de chaque projet)
  Fonts (Google)   : Cormorant Garamond (titres), IBM Plex Sans (corps),
                     IBM Plex Mono (labels/annotations)
  Déploiement      : GitHub Pages via base: '/Portfolio_MD/' dans vite.config.ts
  TypeScript strict : activé (tsconfig.app.json)
  Tests            : aucun pour l'instant

  Dépendances clés dans package.json :
    "framer-motion": "^12.9.2"
    "lucide-react": "^0.511.0"
    "react": "^18.3.1"
    "react-dom": "^18.3.1"
    "react-markdown": "^10.1.0"
    "remark-gfm": "^4.0.0"
    "react-router-dom": "^6.30.1"

  Scripts npm :
    dev     → vite
    build   → tsc -b && vite build
    preview → vite preview

================================================================================
4. ROUTAGE (src/App.tsx)
================================================================================

  BrowserRouter avec basename = import.meta.env.BASE_URL (sans slash final)
  → en production : basename = "/Portfolio_MD"

  Routes définies :
    /                              → <Home />           (eager)
    /projects                      → <Projects />        (eager)
    /projects/:slug                → <ProjectNodePage /> (lazy)
    /projects/:groupId/:projectId  → <ProjectDetail />   (lazy)
    /about                         → <About />           (eager)

  Toutes les pages sont enveloppées dans <Layout> (Nav + Footer).

  Lazy loading :
    ProjectDetail et ProjectNodePage sont chargés en lazy() avec Suspense.
    Fallback : <div className="pageShell">Loading...</div>

  GitHub Pages SPA trick :
    - public/404.html : écrit sessionStorage.redirect = location.href
                        puis redirige vers /Portfolio_MD/
    - index.html      : script inline qui relit sessionStorage.redirect
                        et applique history.replaceState

5. TYPES TYPESCRIPT (src/types/project.ts)
================================================================================

  ProjectDomain (union string) :
    'mechanical' | 'electronic' | 'software' | 'machine-learning'
    | 'design' | 'research' | 'other'

  ProjectLink :
    { label: string; url: string; type: 'github'|'pdf'|'demo'|'external';
      disabled?: boolean }

  ProjectImage :
    { src: string; alt: string; caption?: string }

  Project :
    id: string           — identifiant unique (slug URL)
    title: string
    subtitle?: string
    year: number
    duration?: string    — ex: "Sept. 2024 – Feb. 2025"
    context?: string     — ex: "Course project — Arts et Métiers, Paris"
    domains: ProjectDomain[]
    tags: string[]       — liste libre de mots-clés
    shortDesc: string    — description courte (utilisée dans les cards)
    fullDesc: string     — Markdown complet (rendu sur la page de détail)
    coverImage: string   — chemin /projects/groupe/projet/cover.png
    images?: ProjectImage[]
    links?: ProjectLink[]
    featured?: boolean
    status?: 'completed' | 'in-progress' | 'archived'

  ProjectGroup :
    id: string           — slug URL du groupe
    title: string
    shortDesc: string
    coverImage: string   — chemin /projects/groupe/cover-xxx.png
    domains: ProjectDomain[]
    tags: string[]
    projects: Project[]
    featured?: boolean

12. PARTICULARITÉS & POINTS D'ATTENTION
================================================================================

  1. IMAGES MANQUANTES
     ProjectImage.tsx affiche un fallback (fond grisé + nom de fichier) si
     l'image ne charge pas. Cela évite les erreurs visuelles mais les images
     doivent être placées dans public/projects/ selon les chemins définis dans
     projects.ts.

  2. PDF ACCESSIBLES
     Les PDF référencés ont des URLs relatives sans slash initial :
     'Portfolio_MD/projects/.../.pdf'
     Cela suppose qu'ils sont servis depuis la racine GitHub Pages.
     À surveiller si le déploiement change.

  3. NOTICE PROPRIÉTAIRE
     Les projets 'hydrogen-transport' et 'wellbe' affichent automatiquement
     un bandeau "Proprietary scope notice" dans ProjectDetail.tsx (ligne ~40).
     Pour en ajouter un autre, modifier la condition showProprietaryNotice.

  4. PHOTO DE PROFIL
     Dans About.tsx, la balise image est commentée :
     {/* <img src="/about/photo.jpg" alt="Maxime Denis" /> */}
     Le fichier doit être placé dans public/about/photo.jpg.

  5. RESUME PDF
     Référencé dans About.tsx via :
     href={`${import.meta.env.BASE_URL}resume.pdf`}
     → Doit être dans public/resume.pdf

  6. ORDRE DES PROJETS DANS getAllProjects()
     L'ordre détermine la numérotation "Ref. NNN" et la navigation
     précédent/suivant dans ProjectDetail. L'ordre actuel est :
     design-cad (5 projets) → software-ml (4 projets) → research (3 projets)
     soit 12 projets au total (Ref. 001 à 012).

  7. FEATURED
     Les 3 groupes ont featured: true → tous apparaissent sur Home.
     getFeaturedGroups().slice(0, 4) limite à 4 sur Home (actuellement 3).

  8. standaloneProjects
     Tableau vide ([]). La section standalone dans Projects.tsx est
     conditionnellement cachée. Pour ajouter des projets solo, pousser des
     objets Project dans ce tableau.

  9. DOMAINE 'manufacturing'
     Le dossier public/projects/manufacturing/ existe (mixer-bearing/)
     mais aucun groupe ou projet correspondant n'existe dans projects.ts.
     C'est un dossier résiduel ou prévu pour une future extension.

  10. ANIMATION STAGGER
      ProjectCard et ProjectGroupCard utilisent style={{ animationDelay: `${index * 0.06}s` }}
      pour décaler les apparitions. Cela repose sur la classe CSS .fadeInUp
      définie dans global.css.

  11. FRAMER-MOTION vs CSS animations
      - Home.tsx : animation CSS (.fadeInUp)
      - Projects.tsx, ProjectGroupPage.tsx : framer-motion motion.section
      - ProjectDetail.tsx : CSS (.fadeInUp sur article)
      Il n'y a pas d'incohérence fonctionnelle mais deux systèmes coexistent.
